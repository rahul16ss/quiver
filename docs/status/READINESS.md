## What changed in this pass

- Added `build`, `lint`, `format`/`format:check`, `typecheck`, `check`, `audit:prod` scripts; `check` is serial and cwd-independent (`scripts/check.mjs` invokes tool JS entry points directly — no npm/npx indirection).
- `bin/quiver.js` prefers the compiled `dist/` runtime; tsx is a dev-only fallback for source checkouts.
- `prepack` builds `dist/`; the `files` whitelist keeps the published artifact to bin/dist/docs/examples/packs/profiles/scripts/skills/templates/workflow-packs — no `src/**/*.ts`, no `tests/`, no `.env`.
- `tsconfig.build.json` emits NodeNext ESM to `dist/`; two `.ts`-extension source imports were fixed to `.js`.
- Subagent spawning uses the compiled CLI when built, with a tsx fallback in source checkouts.
- Stale lockfile entries (retired Electron packaging, phantom `google-auth-library`) pruned by reconciling the lockfile to `package.json`.
- ESLint (flat config, node/browser globals) + Prettier are enforced; `no-unused-vars` is error-level repo-wide with zero warnings.
- CI runs `npm run check` + e2e + production audit + `npm pack --dry-run` on Node 22 with pinned action SHAs; the release workflow packages the compiled runtime tarball instead of the retired Electron output.
- `scripts/update_formula.js` is plain JavaScript, syntax-checked, and the Homebrew formula points at the v1.0.0 tag tarball.
