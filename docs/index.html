Quiver

An open foundation for controlled, source-backed document workflows in finance.

The problem

Generic chat tools fall short for investment teams: figures appear without a trail, the model does not know the firm's template or prior work, and the output stays in a chat window instead of the Word, Excel, and PowerPoint files a senior professional actually reviews and signs. The limitation is not drafting speed — it is evidence, format, and control.

What Quiver is

Quiver helps turn approved files, public research, workflow instructions, and review rules into native Office deliverables with inspectable evidence. Conviction Studio uses it as the shared engine for client workflow engagements.

Quiver is infrastructure, not investment advice and not a turnkey replacement for professional judgment. Generated work remains a draft until a professional reviews it.

Reference workflows

The repository ships three executable reference workflow demonstrations across key workflow families:

  • npm run demo:ic-memo — Dealmaking & Diligence: native Word IC memo (Project Alder) with cell-verified evidence map & review checklist.
  • npm run demo:post-earnings — Investment Research: post-earnings evidence pack with transcript & model verification.
  • npm run demo:portfolio-review — Wealth & Portfolio: portfolio review pack with IPS policy & benchmark alignment checks.

Principles

  • Start with the deliverable — native Word, Excel, and PowerPoint files in your house styling.
  • Sources you can inspect — important claims can be connected to cells, pages, sections or URLs—or explicitly flagged for review.
  • Reviewer-in-the-loop governance — drafts require human sign-off; overrides are recorded in a local audit chain.
  • Data handling configured per engagement — model endpoints and privacy boundaries are explicitly set by the operator.
  • Reproducible verification — workflow behavior is validated against explicit acceptance checks.

Data handling

Quiver does not bake in a model endpoint. The operator configures an OpenAI-compatible endpoint via LLM_API_BASE_URL. Local model endpoints are supported. A fully local configuration requires external research and remote connectors to be disabled or separately approved. Memory, sessions, documents, and the audit log live in files on your machine. There is no telemetry.

Install

git clone https://github.com/rahul16ss/quiver.git && cd quiver
npm install
npm run demo:ic-memo   # flagship workflow + acceptance checks
npm test               # run 387 spec acceptance checks
npm run gui            # desktop app
